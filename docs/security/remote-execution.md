# Execução remota isolada

`createRemoteExecutionClient()` is opt-in both when constructing the client and for every execution call. It sends a structured argument vector and a caller-selected set of UTF-8 files over HTTPS to the Worker de referência em [`integrations/cloudflare-sandbox`](../../integrations/cloudflare-sandbox/README.md). Não encaminha variáveis de ambiente, credenciais do CLI ou o workspace inteiro automaticamente.

O Worker autentica por bearer secret, limita o corpo, valida caminhos e argv, cria um ID aleatório de Durable Object por chamada, inicia a imagem resolvida pelo Wrangler com egress desativado, executa argv diretamente sem shell implícito e destrói o container depois. A configuração limita o máximo global a dez containers. Cancelamento do cliente é encaminhado à execução; limites de saída, timeout e orçamento de staging também são aplicados no Worker. A execução deliberada de shells permanece possível dentro do microVM, por isso o conteúdo enviado continua não confiável.

Limites do adapter: até 64 argumentos, 100 arquivos textuais somando 3 MiB, até 240 segundos de comando, 128 KiB para cada canal de saída e 300 segundos para preparação + execução. O cliente limita a resposta a 2 MiB. Caminhos de controle comuns (`.git`, `.env`, `.ssh`, `.aws` e arquivos de credencial usuais) são recusados; revise todo arquivo enviado para remover outros segredos. A aplicação deve autenticar e autorizar o chamador, configurar rate limits e monitorar custo. Não repita automaticamente jobs após timeout de rede: o provider pode ter concluído o primeiro job.

Cada tarefa tem seu próprio Container em microVM e o Worker não habilita Internet de saída. Arquivos e processos continuam compartilhados entre comandos do mesmo job, então não combine dados de tenants distintos no mesmo pedido. Containers requerem conta/plano Cloudflare elegível; o CI usa mocks e valida o contrato do Worker, não uma implantação real na conta Eureka42.

Documentação oficial usada para o adapter: [Cloudflare Durable Object Container API](https://developers.cloudflare.com/containers/api/durable-object-container/), [execução de comandos](https://developers.cloudflare.com/containers/guides/execute-commands/), [configuração Wrangler](https://developers.cloudflare.com/containers/configuration/wrangler/), [visão de Sandboxes](https://developers.cloudflare.com/sandbox/) e [modelo de segurança](https://developers.cloudflare.com/sandbox/concepts/security/).
