# Assumptions

- `PROPOSED`: TypeScript/ESM e monorepo continuam como direção técnica.
- `PROPOSED`: Node >=22 é o piso inicial; a matriz final depende de testes em versões LTS suportadas.
- `CONFIRMED_BY_ENVIRONMENT`: o desenvolvimento inicial ocorre em macOS arm64 com Node 26.8.1.
- `VALIDATION_REQUIRED`: pacote npm, licença, marca, owners e hosts oficialmente suportados.
- `SOURCE_MISSING`: catálogo ASES-300 e metodologia ASES-500 separada.
