# Project Charter

Status: PROPOSED

Construir um framework local-first e vendor-neutral que transforma especificações em requisitos, execução controlada e evidências verificáveis. O trabalho começa por M0/M1: governança mínima, CLI offline, inicialização idempotente, diagnóstico e validação de configuração.

Fora do escopo inicial: publicação, serviços pagos, infraestrutura externa, catálogo normativo inventado e alegações de compatibilidade não testadas.
