# EUREKA42 ASES Framework

Leia primeiro `STATUS.md` e consulte o documento-mestre somente para o escopo em trabalho.

Regras permanentes:

- Não declarar `DONE`, `SUPPORTED` ou `VERIFIED` sem evidência executada.
- O catálogo ASES-300 não está presente; nunca inventar `REQ-001..300`.
- ASES-500 e decisões de arquitetura permanecem `VALIDATION_REQUIRED` ou `PROPOSED` até aprovação humana.
- Trabalhar em incrementos pequenos, offline-first, com testes e atualização de status.
- Não publicar pacotes, criar infraestrutura, usar credenciais ou executar ações destrutivas sem autorização explícita.
- Preservar arquivos existentes e manter mudanças limitadas a este workspace.
- Comandos centrais: `npm test`, `npm run build`, `npm run check` e, quando disponível, os equivalentes `pnpm`.

Fontes: `EUREKA42_ASES_FRAMEWORK_PROMPT_MESTRE_ULTRA_COMPLETO.md`, `docs/SOURCE-REGISTER.md`.
