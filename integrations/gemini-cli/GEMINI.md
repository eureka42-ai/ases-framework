# EUREKA42 ASES

For project discovery, load the `ases-project-start` skill. If the `ases` CLI and terminal are available, run `ases welcome --color` as the first terminal action so the Eureka42 logo appears in green before inspection or questions. Then inspect the workspace before asking about application type, language, hosting, database, scale and sensitive data. Existing choices require evaluation; missing choices receive PROPOSED recommendations. Never silently mark a recommendation CONFIRMED.
