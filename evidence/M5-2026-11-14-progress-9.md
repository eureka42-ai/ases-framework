# M5 progress 9 — host update with backups

Date: 2026-11-14

## Implemented

`ases host update <host> [workspace]` now supports a safe local adapter update lifecycle. It prints a plan without writing by default and requires `--apply` to modify the workspace. The updater only replaces files owned by the selected host whose current SHA-256 still matches the ownership manifest. Before replacement, it copies the current file into `.ases/backups/hosts/<host>/<operation-id>/`; after success, it atomically refreshes the manifest hashes. A locally changed file is reported as a conflict and prevents writes. A partial failure attempts to restore already updated files, and backups remain available after uninstall.
