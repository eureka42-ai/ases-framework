# M15 progress 31 — AFR-134 OIDC SSO and centralized access mapping

Date: 2026-11-15

## Delivered

- Added an embeddable OIDC Authorization Code flow with PKCE S256, one-time state, browser binding, HTTPS discovery/token/JWKS endpoints, RS256 signature verification, and issuer/audience/authorized-party/time/nonce checks.
- Added a one-hour default ID-token age bound, configurable from 60 seconds to 24 hours; unsupported JWT algorithms fail closed.
- Added exact group-to-organization/repository RBAC mapping, optional email-domain allowlist, verified-email default, deny-by-default unmapped groups, conflicting-role rejection, and identity namespaced by issuer/subject hash.
- Added Express `/start` and `/callback` router with secure HttpOnly cookies and trusted-session creation after token and group-policy checks.
- Host retains IdP/client registration, central policy distribution/refresh, TLS ingress, multi-instance session persistence, and revocation lifecycle. Live identity-provider interoperability was not tested.
- References: OpenID Connect Core and Discovery specifications; RFC 9700 and RFC 7636. Links are in `docs/security/oidc-sso.md`.
