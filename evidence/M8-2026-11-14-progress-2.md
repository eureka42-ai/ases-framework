# M8 progress 2 — persisted workflow checkpoints

Date: 2026-11-14

## Implemented

Added workflow checkpoints containing the validated order, completed-step prefix, next step index, definition hash, and update timestamp. Checkpoints are atomically written under `.ases/workflows/` with restrictive file mode and symlink checks on their directories/targets. Resume verifies the current workflow hash and order so changed definitions cannot silently reuse stale state.

## Verification

Automated test saves and reloads a checkpoint, resumes at the next step, rejects a changed definition, and returns no checkpoint for an unknown workflow. Full suite and CI will be recorded before closing these requirements.
