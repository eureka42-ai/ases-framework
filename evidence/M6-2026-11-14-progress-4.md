# M6 progress 4 — capability-aware provider routing

Date: 2026-11-14

## Implemented

Added `selectCapableProvider`, which returns the first configured provider declaring every required capability. It fails with `UNAVAILABLE` when no provider qualifies and rejects an empty capability requirement as invalid input. The router only selects based on declared capabilities; it does not infer or remotely verify provider features.

## Verification

Automated test covers selection among providers, rejection when a required capability is missing, and invalid empty requirements. CI for commit `0bb6dda` passed in Node.js 22 and 24 ([run 43620231088](https://github.com/eureka42-ai/ases-framework/actions/runs/43620231088)).
