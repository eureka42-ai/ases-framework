# M10 progress 2 — safe ContextBundle archive import

Date: 2026-11-14

## Scope

- AFR-082: preview imported paths and conflicts before applying.
- AFR-083: prevent ZIP path traversal and arbitrary execution.

## Implementation

- Added a bounded ZIP reader for single-disk, non-ZIP64 archives using stored or deflate entries. It validates central/local headers, names, sizes, CRCs, duplicate paths, and compression limits.
- Rejects absolute/traversal/platform-specific paths, symlinks and special files, encrypted/unsupported entries, oversized data, and file types outside JSON/Markdown/text.
- `previewBundleArchive()` lists target paths, create/conflict status, byte sizes, SHA-256 hashes, and total size without writing.
- `importBundleArchive()` is read-only unless `apply: true`; it refuses all conflicts without overwriting, writes regular files mode `0600`, never executes imported content, and attempts rollback of created files/directories after a partial failure.
- Exported importer APIs and added an import guide. M10 is now implemented locally; AFR backlog is 79/140 implemented and 61/140 pending.

## Limits

- ZIP64, encrypted, multi-disk, and uncommon compression methods are intentionally unsupported.
- The importer handles untrusted data as inert files. Applications must still validate ContextBundle schemas and decide whether imported instructions or decisions are trusted before consuming them.
