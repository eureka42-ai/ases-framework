# M12 progress 2 — safe plugin removal

Implemented AFR-095 and completed M12 locally:

- Added `ases plugin remove <plugin-id> [workspace]` with read-only plan by default and explicit `--apply`.
- Removal requires a valid hash-bound ownership manifest and deletes only intact, regular files recorded by that manifest.

- Symlinked workspace/plugin parents and tampered manifests fail closed. Empty directories are pruned only within the plugin-owned directory.
