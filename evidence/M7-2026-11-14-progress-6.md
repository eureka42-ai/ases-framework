# M7 progress 6 — on-demand Skill loading

Date: 2026-11-14

## Implemented

Added a Skill loader registry keyed by lowercase IDs. `loadSkillOnDemand` resolves and invokes only the requested loader; malformed and missing IDs fail without invoking the registry. This provides a lazy-loading boundary for hosts that request a Skill by name.

## Verification

Automated test tracks loader invocations and confirms only the selected Skill is loaded; a second test rejects traversal-like and unknown IDs. CI for commit `0836346` passed on Node.js 22 and 24 ([run 43661618404](https://github.com/eureka42-ai/ases-framework/actions/runs/43661618404)).
