# M6 progress 3 — provider capability catalog

Date: 2026-11-14

## Implemented

Added a provenance-bearing provider/model capability record with required provider ID, model ID, capabilities, source, and observation date. Validation rejects empty identifiers or source, invalid calendar dates, unknown/duplicate capabilities, and empty capability sets. The returned record copies the capabilities array to avoid sharing mutable caller state. The record describes a sourced observation; it does not claim live provider verification.
