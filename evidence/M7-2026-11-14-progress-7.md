# M7 progress 7 — runtime tool policy and schemas

Date: 2026-11-14

## Implemented

Added a generic runtime tool executor that parses/validates input, runs the tool, validates output, and returns typed errors for invalid boundaries. A tool marked `sideEffect` cannot run without an authorization callback that resolves to `true`; policy checks occur after input validation and before the effect.
