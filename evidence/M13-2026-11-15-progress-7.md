# M13 progress 7 — migration boundary

Implemented AFR-110 by documenting that the framework does not currently own a database, SQL schema, ORM, or migration runner. The guide distinguishes application database recommendations from framework persistence, describes versioned `.ases` files and verified host backups, and sets rollback, backup-restore, interruption-recovery, and explicit-apply requirements for any future data migration.

This closes the requirement through its documented-limit alternative; it does not claim that database migrations exist.
