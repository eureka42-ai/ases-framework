## Delivered

- Added portable Web Crypto backup encryption: AES-256-GCM, PBKDF2-SHA-256 with fixed 600,000 iterations, random 128-bit salt, random 96-bit IV, 128-bit authentication tag, and authenticated header.
- Added authenticated decryption with a generic error for wrong passphrases/tampered content; passphrases are never serialized.
- Added an explicit `enabled: true` upload/download/delete API and Cloudflare R2 Worker binding adapter. Adapter construction performs no I/O and accepts only the versioned encrypted envelope format.
- R2 receives ciphertext only. Object keys are validated, backup size bounded, reads bounded, and provider error details omitted.
- Restore returns authenticated plaintext bytes to the calling application; it does not write to a workspace. No scheduler/background sync, merge/conflict resolver, or key recovery is provided.
- Documented passphrase recovery responsibility, app-owned R2 configuration/permissions, limits and the host-provider interface.
