# M15 progress 6 — ADR-linked architecture drift checks

## Implemented

- Added `ases architecture check [workspace] [--contracts path] [--json]` and a declarative registry at `docs/architecture/contracts.json`.
- Contracts may check JSON Pointer equality, bounded literal source markers and file presence/absence. Reports include only rule IDs, paths and safe detail messages; observed values and source contents are never printed.
- ADR IDs/headings/status are checked from their Markdown records. Only `ACCEPTED` ADRs enforce drift (exit 1); `PROPOSED` ADR drift remains visible and observational. Missing/ambiguous ADR status or unsafe evidence is `UNVERIFIABLE`; enforced unverifiable checks exit 2.
- All contract, ADR and evidence paths must remain relative to the workspace. Symlinks are not followed, reads are bounded and project code is never executed.
- Added Portuguese/English command references, the architecture-check guide and AFR-123 traceability.
