# M15 progress 2 — local project dashboard

## Implemented

- Added `ases dashboard [workspace] [--product id]`, which writes a self-contained Portuguese HTML snapshot to stdout. Redirect stdout to a file to keep output creation explicit. `--json` returns the same local aggregates as structured JSON.
- The view summarizes requirement states, evidence integrity, saved workflow checkpoints, recent local trace events and recorded costs. Provider-reported and measured costs remain separate; missing costs are never estimated.
- Reads only workspace-local catalog, workflow checkpoint and opt-in trace files. It starts no server, performs no network requests and writes no workspace files. Reads have size/count limits; malformed records are skipped with bounded warnings, HTML text is escaped, and symlinked or out-of-workspace paths are ignored/reported.
- Added Portuguese and English CLI references, observability documentation and requirement traceability for AFR-112.

## Limits

The dashboard is an offline snapshot, not a live server. Its summary lists up to 25 recent traces, while recorded cost aggregates cover the last 5,000 events read from the bounded local file. The interactive browser host was unavailable in this environment, so visual review in a real browser remains unverified; automated checks cover semantic landmarks, CSP, escaping and empty states. The generated stylesheet includes a responsive breakpoint for narrow screens.
