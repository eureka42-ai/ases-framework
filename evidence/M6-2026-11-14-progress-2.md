# M6 progress 2 — enforced offline provider mode

Date: 2026-11-14

## Implemented

Added `generateForMode` to the provider SPI. In `offline` mode it always selects the deterministic local `MockProvider`, including when a caller supplies another provider. For all other modes, a provider must be explicitly supplied or the call fails with the normalized `UNAVAILABLE` error.

## Verification

- Automated test supplies a provider that throws and counts invocations; offline mode returns the mock response and leaves the remote call count at zero.
- Automated test verifies a non-offline mode without a provider fails closed.
- Full `pnpm test` is run for this change before publication.
