# M15 progress 27 — AFR-111 vector-store adapters

Date: 2026-11-15

## Delivered

- Added one `VectorStoreAdapter` interface and implementations for process-local cosine similarity, pgvector over an injected parameterized SQL executor, Qdrant REST, and an injected Cloudflare Vectorize Worker binding.
- Adapters preserve project/source/content hashes/license/version/ACL metadata; query predicates enforce project and principal access, plus optional license/version filters.
- Qdrant requires `enabled: true`, HTTPS and explicit calls; uses bounded requests, sanitized errors, timeouts, deterministic UUID mapping, and Qdrant's current query/delete endpoints.
- Cloudflare uses the host Worker binding, applies project/license/version filters, rechecks ACL in-process, enforces service metadata/query caps, and never constructs credentials or network clients.
- No embedding model, database connection, Cloudflare binding, or remote call is initialized automatically. The application supplies embeddings and owns schema/configuration/credentials.
- Documented schemas, adapter setup, service limits, ACL behavior, and official provider API references in `docs/rag/vector-stores.md`.
