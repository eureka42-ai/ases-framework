# M11 progress 4 — authenticated MCP Streamable HTTP

## Implemented

- Optional `ases mcp <workspace> --http`; stdio remains the default.
- Official MCP TypeScript SDK HTTP handler and Express adapter.
- OAuth Resource Server authentication using RFC 7662 introspection; access tokens are not issued by ASES.
- Validates token `active`, integer expiry, exact resource audience and client identity; requires configured scopes before dispatch.
- Serves authorization-server and protected-resource discovery metadata (RFC 8414/RFC 9728).
- HTTPS is required for non-loopback OAuth endpoints and resource URLs. Network listeners require an HTTPS resource URL and a trusted TLS-terminating proxy. Default listener is loopback.
- 5-second fetch timeouts, redirects disabled, provider response bodies capped at 64 KiB, and sanitized startup/transport errors.
- No token, client secret, request payload, workspace path, or raw provider error is logged.

## Limits

This validates resource-server behavior against a local test verifier; it does not claim production interoperability with a specific identity provider. Deployment requires the operator to configure a compatible OAuth authorization server, introspection client credentials, public resource URL/audience, and TLS proxy. The upstream authorization server is responsible for issuing tokens and enforcing its own client/user policy.
