# M6 progress 6 — constrained provider fallback

Date: 2026-11-14

## Implemented

Added `selectSafeFallback`. It excludes the primary provider and selects only an alternative whose declared data clearance covers the request classification and whose maximum cost does not exceed the original ceiling. If no candidate satisfies both constraints, it fails with `UNAVAILABLE`; invalid cost limits fail closed.

## Verification

Automated test places an insufficient-clearance provider, an over-budget provider, the primary provider, and a valid candidate in sequence; only the valid fallback is selected. A second assertion verifies that no valid candidate produces an error.
