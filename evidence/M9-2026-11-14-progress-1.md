# M9 progress 1 — offline lexical RAG core

Date: 2026-11-14

## Scope

- AFR-069: index local Markdown and text offline.
- AFR-070: retrieve requirement IDs and cite their source.
- AFR-073: retain source and per-chunk hashes.
- AFR-075: return no synthetic answer when nothing is indexed or matched.
- AFR-076: keep vector embeddings optional.

## Implementation

- Added `indexRagSources()` for workspace-contained `.md`, `.markdown`, and `.txt` regular files. It performs no network access and rejects symlinked files and unsupported types.
- Markdown headings stay with their following paragraph, so requirement IDs retrieve their requirement text.
- Added exact `retrieveRequirement()` and deterministic token-overlap `searchRag()` APIs. Results include relative path, line range, source SHA-256, and chunk SHA-256.
- Empty indexes, absent IDs, and queries with no matching token return an empty list. The index explicitly reports `offline-lexical` and `optional-not-configured` embeddings.
- Added tests for indexing and citations, provenance hashes, empty retrieval, and unsafe/unsupported sources.

## Limits

- License/version/ACL filtering, automatic source invalidation, and cross-project permission enforcement remain pending in AFR-071/072/074.
