# M15 progress 1 — traceability graph export

## Implemented

- Added `ases requirements graph [workspace] [--product id]` to export a Mermaid `flowchart LR` from the selected local catalog.
- Requirement nodes connect to recorded decision refs, test refs, evidence and blockers. Evidence nodes include the current integrity classification calculated by the catalog reader.
- Stable SHA-256-derived node IDs avoid using untrusted reference text as Mermaid identifiers. Labels escape HTML-sensitive characters and flatten control newlines; output is sorted and deterministic.
- `--json` returns catalog metadata and the Mermaid text without writing into the workspace.
- Added the generated module to the npm package allowlist and documented its CLI usage in Portuguese and English.
